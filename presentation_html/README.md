# Apresentação HTML

Abra `index.html` em navegador moderno. Chart.js 4.4.1 e fontes DM Sans/Manrope são carregados por CDN, exigindo internet para renderizar os gráficos e tipografia externa.

- Navegação: setas, botões inferior e tecla F para tela cheia.
- PDF: botão “Salvar PDF” e opção de impressão do navegador.
- Proporção desktop: 16:9 padronizada em todos os slides.
- Em telas menores, os slides passam para fluxo vertical responsivo.
- Gráficos usam contêineres com altura definida, canvas absoluto e redimensionamento na troca de slide.
